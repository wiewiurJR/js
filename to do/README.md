# To-Do App

Prosta aplikacja do zarządzania zadaniami, stworzona przy użyciu Node.js, Express.js i EJS.

## Funkcje

- dodawanie nowych zadań
- oznaczanie zadań jako ukończone
- usuwanie zadań
- lokalne zapisywanie zadań w pliku `tasks.json`

## Technologie

- Node.js
- Express.js
- EJS

## Jak uruchomić projekt

1. Otwórz folder projektu w terminalu:

   ```bash
   cd "to do"
   ```

2. Zainstaluj zależności:

   ```bash
   npm install
   ```

3. Uruchom aplikację:

   ```bash
   node app.js
   ```

4. Otwórz w przeglądarce [http://localhost:3000](http://localhost:3000).

Zadania są zapisywane lokalnie w pliku `tasks.json`.
